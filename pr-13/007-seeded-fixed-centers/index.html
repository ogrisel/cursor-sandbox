007 — repeated seeds and shared fixed centers

The breadth comparison is being repeated with initializer seeds 0 through 4. Error bars will show one sample standard deviation across those five independent runs.

This iteration separates two questions:

1. How much do k-means++ basin selection, fit quality, duration, and memory vary with the random seed? 2. When every implementation receives exactly the same starting centers, how do the Lloyd implementations compare?

For the second question, NumPy selects k rows from each dataset without replacement for each seed. The selected float32 rows are saved once and passed unchanged to eager array-API PyTorch on CPU and CUDA, stock scikit-learn, scikit-learn with PRs 23 and 26, and cuML. Each implementation runs both one Lloyd step and a full Lloyd-only fit from those centers. The full fit uses the same 12-iteration budget and variance-scaled tolerance as 006.

The array-API entry point for this path is fit_lloyd. fit_kmeans now composes k-means++ with that same function, so the fixed-center and initialized tracks do not maintain separate iteration loops.
